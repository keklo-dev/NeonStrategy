# Neon Strategy — билды

Готовые сборки игры «Neon Strategy» (Unity). Исходники в репозиторий не входят.

## Что где лежит

| Путь | Содержимое |
|---|---|
| `NeonStrategy.exe` + `NeonStrategy_Data/` + `MonoBleedingEdge/` + `UnityPlayer.dll` + `D3D12/` | Windows x64-билд |
| `NeonStrategy.apk` | Android (debug-подпись, ставится напрямую) |
| `webgl/` | Веб-версия (Unity WebGL) — `index.html` + `Build/` + `TemplateData/` |

## Веб-версия: как запустить

⚠️ **Не открывай `webgl\index.html` напрямую из Проводника** (двойной клик по файлу,
URL `file://`). Unity WebGL не умеет грузить `WebGL.data` по `file://` — будет ошибка
«Не удалось загрузить файл Build/WebGL.data». Нужен локальный HTTP-сервер.

**Просто дважды кликни `Play_Web.bat`** (в корне репозитория или в папке `webgl\`):

1. Батник поднимает крошечный локальный сервер на **PowerShell** (`System.Net.HttpListener`,
   ничего устанавливать не нужно — это часть Windows).
2. Порт: 8080, если занят — ближайший свободный (8081, 8082, …).
3. Браузер откроется сам на `http://localhost:ПОРТ/` — игра загрузится.
4. Закрой консольное окно сервера — сервер остановится.

Детали:

- Работает на чистой Windows: без Python, без Node, без IIS.
- Корректные MIME-типы (`application/wasm` для `.wasm` и т.д.).
- Если сборка пересобрана со сжатием (файлы `.gz`/`.br`), сервер отдаёт их с правильным
  `Content-Encoding` — браузер распакует прозрачно. Текущая сборка НЕ сжата.
- Запасной вариант, если PowerShell вдруг недоступен: `python -m http.server 8080`
  из папки `webgl` (но на обычной Windows он не понадобится).
- Локальная Unity-сборка (`Build\WebGL\` рядом с проектом) тоже умеет: там лежит
  такой же `Play_Web.bat`.

## Windows / Android

- Windows: запустить `NeonStrategy.exe`.
- Android: скопировать `NeonStrategy.apk` на телефон и установить
  (разрешить установку из неизвестных источников).

## Онлайн

Мультиплеер подключается к живому серверу `179.253.173.58:7777` (UDP, Netcode for GameObjects).
Веб-клиент должен открываться по **http://** (не https), иначе WebSocket/UDP-транспорт
к серверу не подключится.
